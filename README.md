# Химия · ҰБТ-ға дайындық — тапсырмалар сайты

Оқушылар жеке кодпен кіріп, химиядан тест тапсырады. Мұғалім тесттерді өзі құрастырады (қолмен немесе Word файлынан), оқушыларды қосады және нәтижелерді көреді. Сайт **толық тегін**: беттері GitHub Pages-те, деректері Supabase-тің тегін жоспарында сақталады. Банк картасы керек емес.

## Не істей алады

**Оқушы:**
- жеке кодпен кіреді (тіркелусіз);
- тест тапсырады: бір дұрыс жауапты, бірнеше дұрыс жауапты, сәйкестендіру және контекстік тапсырмалар;
- жауаптары тапсырғанға дейін құрылғыда сақталады (бетті жауып қайта ашса, жоғалмайды);
- әр тестті **бір рет** қана тапсыра алады;
- тапсырған соң ұпайын және қателерін көреді (мұғалім рұқсат етсе).

**Мұғалім** (`/teacher.html`):
- тест құрастырады: формулалар (H₂SO₄, Fe³⁺), суреттер, кестелер, контекстер;
- **Word (.docx) файлынан** сұрақтарды бірден жүктейді;
- оқушыларды бір-бірлеп немесе тізіммен қосады, кодтарын басып шығарады;
- нәтижелерді сынып бойынша көреді, Excel-ге (CSV) жүктейді, қай сұрақ қиын болғанын көреді;
- оқушыға тестті қайта тапсыруға рұқсат береді.

Бағалау ережесі (сервер жағында есептеледі, оқушы дұрыс жауапты алдын ала көре алмайды):
- бір дұрыс жауапты — дұрыс болса толық ұпай (әдепкі 1);
- бірнеше дұрыс жауапты — әдепкі 2 ұпай: қатесіз — 2, бір қате — 1, екі және одан көп қате — 0;
- сәйкестендіру — әдепкі 2 ұпай: әр қате сәйкестік 1 ұпайды алады.

Әр сұрақтың ұпайын редакторда өзгертуге болады.

## Орнату (бір рет, шамамен 30 минут)

### 1-қадам. GitHub аккаунтын ашу
1. https://github.com/signup бетіне кіріңіз.
2. Поштаңызды, құпиясөзді және пайдаланушы атын (username) енгізіңіз. Username сайт мекенжайында болады, мысалы `aigul-chem` → `https://aigul-chem.github.io/...`
3. Поштаға келген кодпен растаңыз. Тегін (Free) жоспарды таңдаңыз.

### 2-қадам. Supabase жобасын ашу
1. https://supabase.com бетінде **Start your project** → **Continue with GitHub** басыңыз.
2. **New project**:
   - Name: `chem-ubt`
   - Database Password: күрделі құпиясөз ойлап табыңыз (сақтап қойыңыз, бірақ сайтқа керек емес);
   - Region: өзіңізге жақын аймақ (мысалы, **Central EU (Frankfurt)**);
   - Plan: **Free**.
3. **Create new project** басып, 1–2 минут күтіңіз.

### 3-қадам. Дерекқорды баптау
1. `supabase/setup.sql` файлын блокнотпен ашыңыз.
2. Ондағы `MUGALIM_POSHTASY@gmail.com` дегенді **өз поштаңызға** ауыстырыңыз (мұғалім ретінде кіретін пошта).
3. Supabase-те сол жақ мәзірден **SQL Editor** → **New query** ашып, файлдың бүкіл мәтінін көшіріп қойыңыз да, **Run** басыңыз. «Success» шығуы керек.

### 4-қадам. Мұғалім аккаунтын жасау
1. **Authentication → Users → Add user → Create new user**.
2. 3-қадамдағы поштаны және құпиясөзді енгізіңіз, **Auto Confirm User** белгісін қойыңыз → **Create user**.
3. Бөгде адамдар тіркеле алмауы үшін: **Authentication → Sign In / Providers** бөлімінде **Allow new users to sign up** қосқышын **өшіріңіз** → Save.

### 5-қадам. Сайтты Supabase-ке қосу
1. Supabase-те **Project Settings → Data API** (немесе Overview) бетінен **Project URL** көшіріңіз (`https://....supabase.co`).
2. **Project Settings → API Keys** бетінен **Publishable key** (`sb_publishable_...`) көшіріңіз. Ескі жобаларда бұл **anon public** кілті деп аталады.
3. `assets/config.js` файлын ашып, екеуін тиісті орынға қойыңыз:
   ```js
   SUPABASE_URL: "https://abcdefghijkl.supabase.co",
   SUPABASE_ANON_KEY: "sb_publishable_...",
   ```
   Бұл кілт ашық болуы — қалыпты жағдай. Деректерді дерекқордағы қауіпсіздік ережелері қорғайды. **Secret key / service_role** кілтін ешқашан қоймаңыз.

### 6-қадам. GitHub-қа жүктеу
1. GitHub-та оң жақ жоғарыда **+ → New repository**.
2. Repository name: `chem-ubt`, **Public** таңдаңыз → **Create repository**.
3. Ашылған беттен **uploading an existing file** сілтемесін басыңыз.
4. Архивтен шыққан **бүкіл ішіндегісін** (папкалармен бірге: `assets`, `supabase`, `templates`, `.github`, сондай-ақ `index.html`, `teacher.html`, `.nojekyll`, `README.md`) терезеге апарып тастаңыз → **Commit changes**.

   > Windows-та `.github` папкасы мен `.nojekyll` файлы көрінбей қалуы мүмкін. Олар жүктелмесе, **Add file → Create new file** арқылы `.github/workflows/keepalive.yml` атымен файл жасап, мәтінін көшіріп қойыңыз.

### 7-қадам. Сайтты жариялау
1. Репозиторийде **Settings → Pages**.
2. **Source: Deploy from a branch**, Branch: **main**, папка: **/ (root)** → **Save**.
3. 1–2 минуттан кейін сайт мекенжайы шығады: `https://USERNAME.github.io/chem-ubt/`
   - Оқушыларға: `https://USERNAME.github.io/chem-ubt/`
   - Сізге: `https://USERNAME.github.io/chem-ubt/teacher.html`

### 8-қадам. Жобаның «ұйықтап» қалмауы
Supabase тегін жобасы **7 күн бойы ешкім кірмесе** уақытша тоқтайды. Мұның алдын алу үшін репозиторийде автоматты тапсырма бар (3 күнде бір рет дерекқорды «оятады»):
1. Репозиторийде **Actions** қойындысын ашып, сұраса **I understand my workflows, go ahead and enable them** басыңыз.
2. **Supabase keepalive → Run workflow** басып, бір рет қолмен іске қосыңыз. Жасыл белгі шықса — бәрі дұрыс.

Егер жоба бәрібір тоқтап қалса: Supabase → жобаңыз → **Restore project** (деректер өшпейді).

## Күнделікті қолдану

1. `teacher.html` бетіне кіріңіз.
2. **Оқушылар** → тізімді қойыңыз (әр жолға: `Аты-жөні, Сынып`) → **Тізімді қосу**. Кодтарды **🖨 Кодтарды басып шығару** арқылы қағазға шығарып, оқушыларға таратыңыз.
3. **Тесттер → + Жаңа тест** → сұрақтарды қосыңыз немесе **📄 Word (.docx) жүктеу** → **Сақтау**.
4. Тест карточкасында **Оқушыларға көрсету** белгісін қойыңыз — тест оқушыларда пайда болады.
5. **Нәтижелер** қойындысынан қараңыз. Оқушы қайта тапсыруы керек болса — **Қайта тапсыру**.

### Word файлын жазу ережесі
Дайын үлгі: `templates/suraqtar-ulgisi.docx` (мұғалім бетінде **⬇ Үлгі файлды жүктеп алу** батырмасы бар).

```
ТЕСТ: Бейорганикалық химия — 1-нұсқа

1. Азот атомының электрондық формуласы
A) 1s²2s²2p¹
B) 1s²2s²2p³
C) 1s²2s²2p⁵
D) 1s²2s²2p²
Жауап: B

2. [Бірнеше] Қышқылдарды таңдаңыз
A) H₂SO₄
B) NaOH
C) HNO₃
D) Ca(OH)₂
E) H₃PO₄
F) KCl
Жауап: A, C, E

3. [Сәйкестендіру] Зат пен оның класын сәйкестендіріңіз
1) NaCl
2) SO₃
A) негіз
B) тұз
C) қышқылдық оксид
D) амфотерлі оксид
Жауап: 1-B, 2-C

КОНТЕКСТ
Өнеркәсіпте күкірт қышқылын жанасу әдісімен алады: S → SO₂ → SO₃ → H₂SO₄ ...
4. SO₂-нің SO₃-ке тотығуында қолданылатын катализатор
A) V₂O₅
B) Ni
C) Fe
D) Al₂O₃
Жауап: A
5. ...
Жауап: B
КОНТЕКСТ СОҢЫ
```

Маңызды:
- Нұсқаларды `A)`, `B)`... деп **қолмен** жазыңыз. Word-тың автоматты нөмірлеуін қолданбаңыз (әріптер жоғалады).
- Әр сұрақтан кейін **`Жауап:`** жолы міндетті. Түрі жауаптан анықталады: бір әріп → бір жауапты; бірнеше әріп → бірнеше жауапты; `1-B, 2-C` → сәйкестендіру.
- Индекстер: төменгі — **Ctrl + =**, жоғарғы — **Ctrl + Shift + +**. Word-тың «Уравнение / Формула» редакторын қолданбаңыз — ол сайтқа енбейді.
- Сурет пен кестені сұрақ мәтінінің астына қоя беріңіз — олар өздігінен жүктеледі.
- Ұпайды өзгерту үшін `Жауап:` жолынан кейін `Ұпай: 2` деп жазыңыз.
- `#` белгісімен басталатын жолдар — түсініктеме, сайтқа енбейді.
- Жүктегеннен кейін сайт табылған сұрақтар санын және ескертулерді көрсетеді. Сұрақтарды редакторда тексеріп, **Сақтау** басыңыз.

### Редакторда формула жазу
Мәтін өрісіне `H2SO4`, `SO4^2-`, `Fe^3+` деп жазып, **⚗ Формулаларды түзету** батырмасын басыңыз — осы сұрақтағы барлық формула H₂SO₄, SO₄²⁻, Fe³⁺ болып өзгереді. Немесе мәтінді белгілеп **x₂** / **x²** батырмаларын басыңыз. Суретті **🖼 Сурет** батырмасымен немесе Ctrl+V арқылы қоюға болады.

## Шектеулер және кеңестер
- Supabase тегін жоспары: 500 МБ дерекқор, 1 ГБ сурет қоймасы — бірнеше жүз оқушы мен мыңдаған сұраққа жеткілікті.
- Тегін жоспарда автоматты резервтік көшірме жоқ. Тоқсан сайын нәтижелерді **⬇ Excel (CSV) жүктеу** арқылы сақтап қойыңыз, Word файлдарыңызды да сақтаңыз.
- GitHub репозиторийде 60 күн ешқандай өзгеріс болмаса, автоматты тапсырманы (8-қадам) уақытша өшіреді — GitHub поштаға хат жібереді, **Actions** бетінен қайта қосасыз.
- Тест тапсырылғаннан кейін дұрыс жауапты өзгертсеңіз, бұрынғы нәтижелер қайта есептелмейді.
- Оқушы кодын жоғалтса: **Оқушылар → Жаңа код**.
